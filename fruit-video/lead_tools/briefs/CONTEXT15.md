## PHYSICS RULES (E15-PHYS owns the library; every scene that simulates follows these)
`renderAt(t)` must stay a pure function of time. So a simulation is built ONCE (lazily, on first use, deterministic: fixed step 1/240 s, no `Math.random`, no wall clock, seeded noise only), run ahead for the scene's whole duration and sampled at any `lt` (`world.at(lt)`), never stepped frame by frame. Build time must stay under about 1.5 s per scene in the browser (four worker pages each build it). Put the setup of a simulation in a DOM-free module named `ep15_<scene>_sim.js` that exports `build()` (for the browser: `window.__EP15_SIMS.<scene> = { build }`; for node: `module.exports`), so the lead's `node tools_phys_events.js` can run it without a browser and write the collision events for the sound. Each event carries the scene-local time, the position, a magnitude and the material tags of both bodies.

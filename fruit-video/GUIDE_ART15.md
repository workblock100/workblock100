# GUIDE_ART15: the Episode 15 cast kit (`window.A15`, `ep15_art.js`)

Six new characters, a shared tears accessory, props, the Greenleaf uniform. Constructors return `drawChar` options; merge your own `{ x, y (feet), s, t, who, look, expr, arms, grip, hold, hand, acc, yaw, headYaw, noLegs ... }` (defaults: `s` .44, `y` 1316, the dollhouse). Pass `t` (scene-local time) so the idle motion is a pure function of time. Nothing in a sprite is lettered: plates are empty, `A15.plate(o, name)` returns `{ x, y, w, h, rot, size }` (centre, current canvas coordinates; call it after the constructor) for your `UI.label`. Test bench: `art15_demo.html?view=lineup|expr|peel|arti|arti2|onion|cry|tomato|broc|carrot|binder|props|plates|turn|turnrow|perf` (render with `node build/ep15_art/shots.js "<view>[&k=v][@x,y,w,h][#name]"`; `TURNROOT=/tmp/wt_turn/fruit-video` serves TURN's rig).

**Shared:** `A15.cryOn(o, cry)` adds `fp15_tears` to any character (red rims, water in the lower lids, a stream down each cheek, beads, a drip; fits every kind through eyeX/eyeY/er/mouthY). `A15.tearsAura(x, y, u, { r, n, t, size, seed })` mist of droplets round a weeper (pure function of time). `A15.greenleaf(o, { scrubs, lanyard })` dresses any options as Greenleaf staff (drops conflicting accessories). `A15.tagFor(kind or voice id, layers)` -> `{ common, latin, role, lines: [common, latin, role] }` (`lines` is the `UI.tag` content, Latin name italic). `A15.centre(o)`, `A15.PLATES`.

**Props** (`hold`): `fp15_tabletclip` (`tabScale`, `tabAt`, `tabRot`, `tabLit`; `A15.tabletClip(x, y, o)` set piece returns the screen rect), `fp15_laptop` (`lapScale`, `lapBack` shows the lid with the logo, `lapScreen: false` blank screen, `lapOpen`; **`A15.laptopScreen(o)` = the screen rect `[x0, y0, x1, y1]` in the hand's frame (PROP_BOX frame); `A15.laptop(x, y, o)` set piece returns `{ x, y, w, h, cx, cy, rot }`**), `fp15_saladbowl`, `fp15_formstack`, `fp15_megaphone` (`megaWaves` 0..1, `megaAng`). All registered in `PROP_BOX`. **Accessories** (`acc`): `fp15_greenleaf_lanyard`, `fp15_gl_scrubs` (`scrubsHem`), `fp15_visor_badge`, `fp15_hardhat` (`hatColor`, `hatY`), `fp15_tears`, `fp15_headset`, `fp15_onion_glasses`, `fp15_tomato_tag`, `fp15_broc_suit`, `fp15_broc_brows`, `fp15_broc_tag` (the last six come with their constructors).

**Turnarounds (E15-TURN):** every body is a spheroid, dome or cone; faces are the engine's (mapped by the rig); petals, florets, meridians, ribs, ridges, fronds, sepals, sprout, crown are lists with a longitude and turn with `o.yaw` / `o.headYaw`. The kit registers its tables on `V2C.YAW_TEX / YAW_TOP / YAW_ACC / ACC_CLS` when the rig is present (no-op otherwise); kinds carry `yawOwn: true`. Tested 0, 35, 90, 180 degrees. **One engine hook:** a kind may set `k.shoulderAt(side)`; `ep15_art.js` wraps the global `shoulder()` to honour it (carrot, artichoke heart); other kinds fall through unchanged. The artichoke re-sets its kind fields (rx, ry, eye, mouth, arms, legs) and `PATHS.arti` from the peel in the constructor (and again in its accessory): draw each artichoke right after constructing it. Performance at s 1 (headless): artichoke 1.8 ms (4.3 mid-peel), broccoli 4.1, others under 1.
